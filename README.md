One word describing home Wi-Fi: **Gaslighting** — full signal bars, nothing
loads, and the router insists everything is fine.

## Run

```sh
node main.ts
```

Writes the word to `/output/entry.txt` (11 characters, inside the gate of
1–20 UTF-8 characters, not only whitespace). Node 22+ only, no dependencies.
